## 使い方

- 単体版：PTOT_3subjects_v1.32.htmlをブラウザで開いてください。画像を内蔵しています。
- PWA版：PTOT_PWA_v1.32.zipを展開し、index.html・sw.js・manifest・icons・images等をGitHub Pagesの公開場所に配置してください。ZIPファイルそのものではなく展開した内容を配置します。
- GitHubへの反映は行っていません。公開済みページを更新した後は再読み込みして、画面のv1.32を確認してください。
