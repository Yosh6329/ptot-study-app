# PT・OT 3科目分析アプリ v1.33

## 今回の変更

- 確認テスト・分野別演習・今日の復習・関連問題・検索からの単問演習で、下部メニューを常時表示します。
- 出題画面の上部と下部に「中断してホームへ」を表示します。
- メニュー移動時には進行状況を自動保存します。通常演習と復習は、ホームの「中断した演習・復習」から再開できます。
- 問題の順番・現在位置・選択中の回答・確信度を保存し、回答後は解説画面へ戻ります。ページを再読み込みした場合もホームから再開できます。
- 再開だけでは回答を再登録しません。通常演習・復習の回答済み結果は履歴に保存済みです。確認テストは従来どおり全問終了時に分析へ反映します。
- 「この続きは終了」は未完了の演習・復習の再開枠だけを削除します。回答済みの履歴は残ります。
- 複数の演習を中断した場合、それぞれ再開できます。完了した演習の再開枠は自動で消えます。

## 利用方法

単体HTMLはブラウザで開いてください。PWA ZIPは展開した内容をGitHub Pagesの公開場所に配置してください。公開更新後は再読み込みし、画面のv1.33を確認してください。GitHubへの反映は行っていません。

問題データ・原問・選択肢・採点・分野はv1.32と同じで、画面の修正はv1.32.1も引き継いでいます。解答記録の問題データ版は1.32を継続します。

再開用の状態・履歴は使用中のブラウザに保存されます。別端末・別ブラウザ・別URLの公開場所には自動では移りません。
